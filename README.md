# MERN E-Commerce Store

A full-stack E-Commerce web application built using the MERN Stack (MongoDB, Express.js, React, Node.js). The application provides a complete online shopping experience with product browsing, shopping cart, user authentication, wishlist management, reviews, product filtering, and an admin dashboard for product and category management.

---

## Features

### User Features

- User Registration & Login (JWT Authentication)
- Browse Products
- Product Details Page
- Category & Brand Filtering
- Price Range Filtering
- Search Products
- Shopping Cart
- Wishlist (Favorites)
- Product Reviews & Ratings
- Order Placement
- Responsive UI

### Admin Features

- Admin Authentication
- Product Management (Add, Edit, Delete)
- Category Management
- User Management
- Order Management

## Installation

Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/MERN-ecommerce-store.git
```

Go to the project directory

```bash
cd MERN-ecommerce-store
```

Install dependencies

Frontend

```bash
cd frontend
npm install
```

Backend

```bash
cd backend
npm install
```

---

## Environment Variables

Create a `.env` file inside the backend folder.

```env
PORT=5000
MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_secret_key
```

---

## Run the Project

Backend

```bash
npm run server
```

Frontend

```bash
npm run dev
```
